## 🚀 Quick Start (Local Run)

### Windows
ডাবল-ক্লিক করুন:
```
preview-windows.bat
```
এটি স্বয়ংক্রিয়ভাবে সার্ভার চালু করবে এবং আপনার ব্রাউজারে `http://localhost:3000` ওপেন করবে।

অথবা টার্মিনালে:
```bash
npm run dev
```

### অ্যাডমিন প্যানেলের ক্ষমতা:
1. **New Project:** যেকোনো নতুন প্রজেক্ট মুহূর্তেই তৈরি করুন।
2. **Direct Image Upload:** ড্র্যাগ অ্যান্ড ড্রপ বা ব্রাউজ করে হাই-রেজুলেশন প্যাকেজিং ছবি আপলোড করুন (ছবি স্বয়ংক্রিয়ভাবে সার্ভারে সেভ হবে)।
3. **The 5-Phase Packaging Journey:**
   - **Phase 01:** Client Brief & Market Challenge
   - **Phase 02:** Dieline Blueprint & Sketches
   - **Phase 03:** Final 3D Packaging Look
   - **Phase 04:** Print & Technical Specs (Rotogravure / Offset / Pantone)
   - **Phase 05:** Supermarket Reality & Shelf Presence (আসল পণ্যের ছবি)
4. **Print & Dieline Specifications:** প্যাকেটের ধরন, সাবস্ট্রেট (BOPP, Met-PET), কালার প্রসেস এবং স্পেশাল ফিনিশিং (Spot UV, Foil)।
5. **Instant Live Publish:** "Save & Publish" বাটনে চাপলেই তা সাথে সাথে লাইভ ওয়েবসাইটে দেখা যাবে।
6. **Profile Editor:** আপনার নিজের বায়ো, অভিজ্ঞতা, পদবি এবং যোগাযোগের তথ্য আপডেট করুন।

## 🌐 ফ্রিতে অনলাইনে লাইভ ও ডোমেইন যুক্ত করার উপায় (Vercel)

আপনার ওয়েবসাইটটি ইন্টারনেটে ফ্রি লাইভ করতে:
1. এই ফোল্ডারটিকে আপনার GitHub অ্যাকাউন্টে একটি নতুন রিপোজিটরিতে পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Zasim packaging portfolio & admin studio"
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```
2. [Vercel.com](https://vercel.com)-এ গিয়ে আপনার GitHub দিয়ে লগইন করুন এবং প্রজেক্টটি **Import** করুন।
3. **Environment Variables**-এ যোগ করুন:
   * `ADMIN_PASSWORD`: আপনার গোপন পাসওয়ার্ড
4. **Deploy** বাটনে চাপুন! ২ মিনিটের মধ্যে আপনার ওয়েবসাইট বিশ্বব্যাপী লাইভ হয়ে যাবে।
5. আপনার কেনা ডোমেইন (যেমন: `zasim.design` বা `zasimuddin.com`) Vercel Settings $\to$ Domains-এ গিয়ে যুক্ত করে দিন।
